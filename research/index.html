Research overview

Summary

The legacy 4D CDT code was audited and its Monte Carlo sampler found to be biased. A corrected sampler was written, the 2D, 3D and 4D codes were combined into a single C++ codebase, and the results were compared with published values.

Background

The starting point was a set of legacy CDT codes written in Common Lisp at UC Davis: a 2+1-dimensional code and a 3+1-dimensional (4D) code by Rajesh Kommu, a Hořava–Lifshitz variant by Christian Anderson, and fixed-boundary versions by Jonah Miller and David Kamensky. The aim was to obtain a code suitable for new 4D measurements and, eventually, a single codebase covering two, three and four dimensions.

Results from a simulation code are meaningful only if it samples the intended probability distribution. The first step was therefore an audit.

Stages of the work

  1. Audit. The 4D Lisp code was compared with the paper of Ambjørn, Jurkiewicz and Loll and with five reference codes, using an independent invariant checker and an exact enumeration of its proposal kernel. The geometry is correct, including all ten moves, the Regge action and the bookkeeping. The Monte Carlo sampler violates detailed balance in several respects, so its results cannot be compared quantitatively with the literature. Audit.
  2. Correction. A corrected Metropolis–Hastings sampler was written for the same geometry, with O(1) site bags, one site per proposal, exact Hastings factors and quadratic volume fixing. An exact kernel test over more than 2,300 move instances confirms detailed balance to \(2\cdot10^{-15}\), with no irreversible moves.
  3. Unified codebase. A single C++ codebase for 2D, 3D and 4D CDT was built from JorenB's 2d-cdt and 3d-cdt, with the corrected 4D sampler ported to it. The same kernel test applied to the upstream 2D and 3D codes found four acceptance-ratio errors, which have been corrected. The 4D port agrees with the Lisp code move by move and is about 6.5 times faster. Code.
  4. Validation. The corrected codes were compared with published results: the de Sitter profile, the volume fluctuations, the phase structure, the A–C transition and the spectral dimension in 4D, and the quantum Ricci curvature profile in 2D. They agree wherever the available volumes permit a test. Validation.

Main findings

  • The legacy 4D sampler has no Hastings factor. For the (2,8)/(8,2) pair this is equivalent to shifting \(\kappa_0\) by \(-\ln 4 \approx -1.39\); for the other moves the bias depends on the local configuration. About 1% of (4,6) moves cannot be reversed.
  • The upstream 3D code (3d-cdt) used an incorrect Hastings factor for its add and delete moves, and therefore effectively simulated \(k_0 - \ln 2\) rather than the configured \(k_0\). The upstream 2D code over-accepted deletions at the target volume by 8%.
  • The corrected 4D code reproduces the published phase B, the location of the A–C transition and the jump of \(N_0/N_4\) across it, the ratio \(N_{32}/N_{41}\), the fluctuation coefficient \(k_1 = 0.0389 \pm 0.0011\) (published 0.038), the de Sitter width \(s_0 = 0.56 \pm 0.04\) (published 0.59), and the spectral dimension within its errors (about 0.02) of the published curve up to \(\sigma = 100\).
  • An earlier failure to reproduce phase B at small volume is explained by a slow, metastable state, not by a difference between the codes.
  • The 2D curvature profiles of Brunekreef and Loll (arXiv:2110.11100) are reproduced; the error in the upstream 2D code has no visible effect on them.

Methodology

  • Original sources unmodified. Every audit was run on the original sources. Corrected versions are kept separately, so that the two can be compared.
  • Exact tests of the sampler. On small triangulations every possible proposal can be enumerated, so the ratio of forward and backward proposal probabilities can be compared with the acceptance rule to machine precision.
  • Byte-identical baselines. Each change to imported code is checked against fixed-seed outputs, which it either reproduces exactly or changes in a documented way.
  • Comparison with published values, with each result classified as agreeing, partially agreeing, or not reproduced.
